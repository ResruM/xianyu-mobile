   📥 一行命令下载（最快，推荐）
════════════════════════════════════════

在你的手机终端里，直接复制粘贴下面这行，回车即可：

curl -L -o xianyu-mobile.zip "https://github.com/ResruM/xianyu-mobile/releases/download/v2.1/xianyu-mobile.zip"
unzip xianyu-mobile.zip
cd xianyu-mobile
sh install.sh

────────────────────────────────────────
如果上面的 curl 报错，试试这条备用源：

curl -L -o xianyu-mobile.zip "https://github.com/ResruM/xianyu-mobile/archive/refs/heads/main.zip"
unzip xianyu-mobile.zip
cd xianyu-mobile-main
sh install.sh

────────────────────────────────────────
也可以手动下载后传进手机：

  下载地址（浏览器打开即可下载）：
  https://github.com/ResruM/xianyu-mobile/releases/download/v2.1/xianyu-mobile.zip

  或者访问项目主页，点 Code → Download ZIP
  https://github.com/ResruM/xianyu-mobile
