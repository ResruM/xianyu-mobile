════════════════════════════════════════
   安卓手机 安装教程（Termux 版）
════════════════════════════════════════

适用：安卓 7.0 以上，全部免费，不需要电脑（抓 Cookie 那步除外）。
预计耗时：15 分钟


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第 0 步：安装 Termux（重点：别用应用商店的）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

⚠️ 应用商店里的 Termux 已经停更且装不了包，一定要用官方渠道。

推荐途径（任选一个）：

  ● F-Droid 应用商店
    1. 浏览器打开 https://f-droid.org
    2. 下载 F-Droid 安装
    3. 在里面搜 Termux，安装

  ● 或者直接从 GitHub 下载
    浏览器打开 https://github.com/termux/termux-app/releases
    下载 arm64-v8a 的 apk 安装

装好后打开，会看到一个黑色命令行窗口。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第 1 步：装基础环境（5 分钟）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

在 Termux 里依次输入下面两条，每条按回车：

    pkg update -y
    pkg install -y python unzip

跑完看到回到 $ 提示符就好了。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第 2 步：让 Termux 能访问手机文件
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

输入：

    termux-setup-storage

手机会弹出权限请求，点「允许」。

之后你的手机存储会映射到 ~/storage 目录：
    ~/storage/downloads   对应手机的「下载」文件夹
    ~/storage/shared      对应手机内部存储根目录


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第 3 步：把安装包下载到手机
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

打开手机浏览器，访问我们发给你的网盘链接，
输入提取码，把 xianyu-mobile.zip 下载下来。

下载完的文件通常在「下载」文件夹里。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第 4 步：解压并安装（3 分钟）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

回到 Termux，依次执行：

    cd ~/storage/downloads
    unzip xianyu-mobile.zip
    cd xianyu-mobile
    sh install.sh

最后看到「安装完成！」就成功了。

⚠️ 如果提示找不到文件，先执行 ls 看看文件名是不是带后缀，
   比如 xianyu-mobile(1).zip，那就把命令里的名字改一致。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第 5 步：配置（5 分钟，只需一次）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    python3 setup.py

会一步步问你：

  ● 选模型 → 直接回车（默认 DeepSeek）
  ● 填 API Key
     浏览器打开 https://platform.deepseek.com 注册
     充值 10 元，在「API Keys」里创建，复制粘贴进来
  ● 贴闲鱼 Cookie
     这一步需要一个电脑浏览器，见下面说明
  ● 其他设置 → 一路回车

配置成功会显示「配置完成！」


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第 6 步：启动
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    python3 run.py

看到三行就是成功了：

    Token获取成功
    Token刷新成功
    连接注册完成


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
安卓挂机设置（关键，不做会掉线）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Termux 比 iPhone 稳得多，但要做三件事：

1. 阻止息屏断连
   在 Termux 里执行：
       termux-wake-lock

2. 关闭电池优化
   手机设置 → 应用管理 → Termux → 电池 → 选「不限制」
   （不同品牌路径略有差异，小米/华为/OPPO 都要单独设置）

3. 允许后台运行
   手机设置 → 应用管理 → Termux → 允许后台活动

做完这三步，一般能挂好几天不断。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: pkg update 卡住不动？
A: 换国内源，执行：
   termux-change-repo
   选一个国内的镜像（如清华 TUNA），然后重新 pkg update

Q: 提示 termux-setup-storage 无效？
A: 到手机设置 → 应用 → Termux → 权限，手动打开「存储」权限

Q: 提示 Permission denied
A: 确认第 2 步执行过 termux-setup-storage

Q: 装 openai 很慢？
A: setup 会自动换源。如果还是慢，先在 Termux 里执行：
   pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple

Q: Termux 通知栏一直有通知？
A: 那是 wake-lock 在起作用，正常现象，别点掉

Q: 手机重启后要重新启动吗？
A: 是的。重新打开 Termux，执行：
   cd xianyu-mobile
   python3 run.py

额外：怎么抓闲鱼 Cookie
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

推荐用电脑操作（最简单）：
  1. 电脑浏览器打开 https://www.goofish.com 并登录
  2. 按 F12 → Network（网络）标签
  3. 点 Fetch/XHR
  4. 刷新页面
  5. 点任意请求 → Headers → Request Headers
  6. 找到 Cookie: 这一行，复制冒号后面全部内容
  7. 必须包含 unb= 这一段

复制后可以：
  ● 通过微信/QQ 发给自己，再从手机复制粘贴到 setup.py
  ● 或保存成 txt 文件传到手机
