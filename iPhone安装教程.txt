   iPhone 安装教程（iSH 版）
════════════════════════════════════════

适用：iPhone / iPad（iOS 14 以上），全部免费。
预计耗时：20 分钟

⚠️ 先说结论：iPhone 能用，但不如安卓稳。
   iOS 会挂起后台 App，长期挂机建议用安卓、电脑或云服务器。
   如果你只是想偶尔用用，iPhone 也够。

⚠️ 提前说明：抓 Cookie 这一步需要一台电脑，
   纯手机操作会很麻烦。如果你没有电脑，
   可以找朋友帮忙抓一次，Cookie 能用好几周。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第 0 步：安装 iSH（2 分钟）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. App Store 搜索「iSH」（图标黑色，免费）
2. 下载并打开

会看到一个黑色命令行窗口，底部有键盘。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第 1 步：装基础环境（5 分钟）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

在 iSH 里输入这一行，按回车：

    apk add python3 py3-pip unzip

会刷出一屏 Installing xxx，
最后出现 "OK: xx MiB in xx packages" 就成功了。

⚠️ 如果卡住不动超过 3 分钟，按屏幕「^C」中断，
   然后换源重试（见文末常见问题）。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第 2 步：把安装包放进 iSH（最容易卡的一步）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

iSH 默认看不到「文件」App 的内容，所以要这样做：

  A. 先在 Safari 打开网盘链接，下载 xianyu-mobile.zip
     文件会存到「文件」App →「下载」里

  B. 打开 iSH，把「文件」App 里的文件搬进来

     方式一：用 iCloud 中转（推荐，最省事）
       1. iSH 里执行：
              cd ~
       2. 打开「文件」App，长按 xianyu-mobile.zip
       3. 选「拷贝」
       4. 前往「iCloud 云盘」→「iSH」文件夹
       5. 粘贴进去
       6. 回到 iSH，执行 ls，应该能看到 xianyu-mobile.zip

       如果找不到 iCloud 里的 iSH 文件夹，
       请在 iSH 里执行一次：
              mkdir -p ~/Documents
       然后再看「文件」App 里是否出现 iSH。

     方式二：直接在线下载（如果卖家提供了直链）
       在 iSH 里执行：
              curl -L -o xianyu-mobile.zip "下载直链"
       这种方式最快，不需要搬运文件。

  C. 确认文件到位
     执行：
          ls -lh xianyu-mobile.zip
     能看到文件大小就对了。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第 3 步：解压并安装（3 分钟）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    unzip xianyu-mobile.zip
    cd xianyu-mobile
    sh install.sh

看到「安装完成！」就成功了。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第 4 步：配置（5 分钟，只需一次）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    python3 setup.py

按提示走：

  ● 选模型 → 直接回车（默认 DeepSeek）
  ● 填 API Key
     手机浏览器打开 https://platform.deepseek.com
     注册、充值 10 元、创建 Key，复制粘贴
  ● 贴闲鱼 Cookie（需要电脑，见文末）
  ● 其他 → 一路回车

显示「配置完成！」就好了。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
第 5 步：启动
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

    python3 run.py

看到三行就成功：

    Token获取成功
    Token刷新成功
    连接注册完成


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
iPhone 挂机注意事项（务必看）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

iOS 系统会挂起后台 App，实际表现：

  ● iSH 保持在前台          → 正常工作
  ● 切到别的 App 或锁屏     → 几十秒到几分钟后断开
  ● 断开后 AI 不回复         → 会漏消息

能做的缓解：

  1. 插上充电器，屏幕自动锁定时间设为「永不」
     设置 → 显示与亮度 → 自动锁定 → 永不
  2. 把 iSH 一直放在前台，别切走
  3. 程序会自动重连，断线后恢复大约需要 5-10 秒

如果你需要 7×24 稳定挂机，
建议改用安卓手机（Termux）或电脑，差距很大。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
常见问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: apk add 超级慢或者卡住？
A: 换源。依次执行：

   echo "https://mirrors.aliyun.com/alpine/v3.21/main" >  /etc/apk/repositories
   echo "https://mirrors.aliyun.com/alpine/v3.21/community" >> /etc/apk/repositories
   apk update
   apk add python3 py3-pip unzip

   （如果提示 v3.21 不存在，把 3.21 换成 3.20 或 3.19）

Q: 提示 -sh: unzip: not found？
A: 忘了装 unzip，执行 apk add unzip

Q: 提示 command not found: python3？
A: 第 1 步没装上，重跑 apk add python3 py3-pip

Q: 文件怎么也放不进 iSH？
A: 用「方式二」在线下载最省事：
   向卖家要一个能直接 curl 的链接，
   或者用其他网盘（如蓝奏云）的直链。

Q: 锁屏就断，怎么办？
A: 这是 iOS 限制，无解。
   可以设置 → 显示与亮度 → 自动锁定 → 永不，
   但会耗电。长期用建议换安卓或电脑。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
怎么抓闲鱼 Cookie（需要电脑）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 电脑浏览器打开 https://www.goofish.com 并登录
2. 按 F12 打开开发者工具
3. 点上方 Network（网络）
4. 点 Fetch/XHR 过滤
5. 刷新页面（F5）
6. 左边随便点一个请求
7. 右边 Headers → Request Headers
8. 找 Cookie: 这一行，复制冒号后面全部内容
9. 必须包含 unb= 这一段

复制后，通过微信/QQ 文件传输助手发到手机，
再从手机复制粘贴到 setup.py 里。

⚠️ 抓完后别退出登录，否则 Cookie 立刻失效。
