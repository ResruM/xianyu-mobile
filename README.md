# 闲鱼 AI 自动回复助手

让你的闲鱼账号 7×24 小时自动回复买家，不用一直盯着手机。

- 商品咨询自动答疑
- 自动议价，按你的策略让价
- 模拟真人打字延迟，看起来不像机器人
- 随时人工接管，发个句号就让 AI 闭嘴

---

## 一、你需要准备什么

| 项目 | 说明 |
|---|---|
| 一台手机或电脑 | iPhone（装 iSH）或任意电脑 |
| 一个 AI 模型 Key | DeepSeek 最便宜，充 10 块能用很久 |
| 你的闲鱼 Cookie | 复制一次，能用几周 |

---

## 二、安装（约 3 分钟）

### 方案 A：iPhone（iSH，免费）

1. App Store 搜索 **iSH** 安装
2. 打开 iSH，依次执行下面三行：

```sh
apk add python3 py3-pip
```

把本项目的文件夹放到 iSH 里（用 iCloud 或文件 App 传进去），然后：

```sh
cd 你的文件夹路径
sh install.sh
```

### 方案 B：电脑（Windows / Mac / Linux）

**Mac / Linux：**

```bash
cd 项目文件夹
sh install.sh
```

**Windows：**
先安装 Python 3.8+（勾选 Add to PATH），然后在项目文件夹打开命令行：

```bat
python -m pip install -r requirements.txt
```

## 三、配置（只需一次）

```sh
python3 setup.py
```

向导会一步步问你：

**第 1 步：选模型**

直接按回车用 DeepSeek（推荐，便宜稳定）。

**第 2 步：填 API Key**

去 https://platform.deepseek.com 注册，创建 API Key，粘进去。向导会自动测试能不能连通，连不上会提示你。

**第 3 步：填闲鱼 Cookie**

这一步最关键，照做：

1. 电脑浏览器打开 https://www.goofish.com ，扫码登录你的闲鱼
2. 按 `F12` 打开开发者工具
3. 点上方 **Network（网络）** 标签
4. 点 **Fetch/XHR** 过滤
5. **刷新页面**（F5）
6. 左边随便点一个请求
7. 右边 **Headers → Request Headers**，找到 **`Cookie:`** 那一行
8. 复制冒号后面**全部内容**（很长一串）

> ⚠️ 必须包含 `unb=` 这一段，否则是没登录成功。
> ⚠️ 抓完别退出登录、别关那个页面，Cookie 会立刻失效。

粘进去后，向导会显示"识别到 N 个字段，用户ID: xxx"，看到这个就对了。

**第 4 步：其他设置**

直接回车即可。默认接管词是句号「。」。

## 五、日常使用

### 查看状态

```sh
python3 status.py
```

会显示：是否在线、用的什么模型、最近聊了什么。

### 停止

```sh
python3 stop.py
```

或者直接按 `Ctrl+C`。

### 人工接管

在闲鱼里跟某个买家聊的时候，**发一个句号「。」**，AI 就停止回复这个买家，你接手。
再发一个句号，AI 恢复自动回复。

> 这个只能在闲鱼 App 里操作，这是设计如此。

### 改 AI 说话风格

编辑 `prompts/` 里的文件：

| 文件 | 作用 |
|---|---|
| `default_prompt.txt` | 一般咨询的回复风格 |
| `price_prompt.txt` | 议价策略 |
| `tech_prompt.txt` | 技术问题 |
| `classify_prompt.txt` | 判断买家问什么 |

改完重启即可生效。

## 六、常见问题

**Q：一直提示 Cookie 无效？**
重新抓一次 Cookie，确认包含 `unb=`。注意要在 goofish.com 上抓，不是 taobao.com。

**Q：过了几周突然不回复了？**
Cookie 过期了，重新抓一次，运行 `python3 setup.py` 覆盖配置即可。

**Q：AI 说的话不对 / 乱承诺？**
修改 `prompts/` 里的提示词。特别是价格相关，一定要改成符合你实际商品情况的说法。

**Q：iPhone 上为什么老是断？**
iOS 会挂起后台 App。建议：
- 让 iSH 保持在前台
- 或者用电脑 / 云服务器跑，更稳定

**Q：能同时在手机和电脑上跑吗？**
❌ 不能。同一个账号两个程序同时跑会互相抢消息，导致消息丢失。**只能开一个。**

## 七、注意事项

1. **这是自动化工具，有一定风险**。闲鱼可能会检测异常行为，建议控制回复频率，别太激进。
2. **AI 会犯错**。谈价格、承诺服务这类事，建议定期用 `status.py` 看对话记录，发现问题及时改提示词。
3. **不要拿它做违规的事**。刷单、欺骗买家之类的行为会导致封号。
4. **Cookie 等于账号密码**，不要泄露给任何人。
